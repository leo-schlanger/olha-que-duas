Instruções para criar a imagem OG

Esta imagem deve ter 1200x630 pixels e ser salva como og-image.png na pasta /public/.

Como capturar esta imagem:

  • Abra este arquivo HTML num browser
  • Use as DevTools (F12) para capturar o elemento .og-image
  • Ou use ferramentas como Puppeteer, Playwright, ou serviços online
  • Exporte em PNG com fundo opaco

Alternativas para criar a imagem:

  • Canva: Crie um design 1200x630 com a logo e cores da marca
  • Figma: Use este design como referência
  • OG Image Generator: Use ferramentas como og-image.vercel.app

Cores da marca:

  • Vermelho: #b4292b
  • Amarelo/Dourado: #FFD700
  • Charcoal: #1a1a1a
  • Cream: #FAF8F5
